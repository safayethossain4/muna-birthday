MUNA PAKHI — BIRTHDAY WEBSITE
==============================
This version is intentionally a single-page website that reveals one chapter at a time.
There is no big menu. Click the main button to move to the next page/chapter.

RUN:
1. Extract the ZIP.
2. Open the muna_birthday_website folder in VS Code.
3. Right-click index.html > Open with Live Server.

MUSIC:
- Put your MP3 in images/ and name it our-song.mp3.
- The website tries to start music when it opens, but modern browsers often block autoplay with sound.
- Music will start when she clicks/taps the page or the first "Open your surprise" button.
- Use the music button in the top-right to pause/play.

PHOTOS:
- "Add our photos" previews chosen photos while the page is open.
- To keep photos on the site, copy them into images/ and replace sample image URLs in index.html with e.g. images/our-first-photo.jpg.
- Sample gallery photos need internet.

PERSONAL DETAILS:
- Name: Muna
- Nickname: Moina Pakhi (ময়না পাখি)
- Birthday: 25 October 2006
The age/date isn't shown as a countdown because the date of birth is in the past; this is a birthday greeting experience.
